# Guided decisions and local workspace

/get-started recommends skippable journeys for pricing, paperwork, order profit and scenario comparison. It links existing tools and the new workbench. It does not copy private calculator inputs across routes automatically. Document handoffs remain explicit and tab-local.

/decision-workbench compares up to three named price/cost/discount/volume scenarios. Money uses Decimal arithmetic and paise rounding. Break-even calls the existing business-economics engine. Non-positive contribution produces an unavailable break-even, not a recommended price. Downside cases lower volume by 20% (whole units rounded down) or raise combined variable/delivery costs by 10%, independently. Users must use a consistent period and exclude taxes from this commercial comparison. These are assumptions, not demand forecasts or advice.

/workspace persists only after explicit saves. Profile, comparison assumptions and up to 20 document drafts are stored under karobarkit:workspace:v1, capped at 512 KB. No accounts, cloud sync, encryption guarantee or automatic backups are introduced. Anyone with browser-profile access can read the data. Logos are excluded. The first supported draft forms are quotation, commercial invoice and payment receipt; GST invoices are not yet part of this device-workspace integration. Required-field and arithmetic validation still runs on document export. Profile application ignores blank stored fields and requests confirmation. Restoring a draft replaces form fields only after confirmation.

Backups are private JSON files with versioned strict headers, bounded field sizes and supported document structures. Invalid or unsupported backups are rejected before storage changes. Restoring a valid backup requires replacement confirmation. There are duplicate/delete draft actions and full workspace deletion; downloaded files are never deleted by these controls. Corrupt storage can be explicitly cleared. The management screen detects changes made by another page before overwriting its opened snapshot. Document saves and workbench saves merge into the latest workspace.

Nothing from the workspace is transmitted to analytics. Existing production custom-event analytics remains disabled. These features demonstrate product design and deterministic modeling; no adoption, retention gain, interview findings or commercial results are claimed.

Acceptance: goal selection leads to the appropriate next step; scenario changes reconcile revenue, costs and profit; negative contribution and invalid inputs remain understandable; saved comparisons reload; business details apply only on request; incomplete document drafts can be saved and reloaded; duplicate/delete works; backups can be downloaded and validated before restore; clearing removes the storage key; blocked or full storage reports failure instead of success.

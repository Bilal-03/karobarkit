# SEO launch audit

- Unique title, description, H1 and canonical: covered by route metadata E2E and unit tests.
- Sitemap: `/sitemap.xml` returns 200 and contains the intended static, category and tool URLs; search-query variants are excluded.
- Robots: `/robots.txt` returns 200, allows public routes and declares `/sitemap.xml`.
- Open Graph/Twitter metadata: generated by the shared metadata helper.
- Structured data: WebSite, WebApplication, BreadcrumbList and visible FAQPage JSON-LD are generated from static content.
- Internal links: homepage, categories, tools, methodology, sources and error reporting are covered by E2E discovery journeys.
- 404: custom page includes search, home, tools and categories.
- Search: `noindex,follow` prevents query-result duplication.

Production-domain and `www`/non-`www` redirect behavior cannot be verified because no production domain is configured in the repository. This remains a deployment prerequisite.

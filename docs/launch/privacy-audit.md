# Privacy audit

The active tool set is browser-local. No server endpoint receives calculator, QR, logo or document values.

| Data class                                       | Analytics                                    | Logs       | URL/query                                                  | Browser storage                           | Verdict                                                           |
| ------------------------------------------------ | -------------------------------------------- | ---------- | ---------------------------------------------------------- | ----------------------------------------- | ----------------------------------------------------------------- |
| Financial inputs/results                         | Forbidden                                    | Not logged | Not placed in URL                                          | None by default; opt-in tab transfer only | PASS                                                              |
| GSTIN, names, addresses, invoice/receipt details | Forbidden                                    | Not logged | Not placed in URL                                          | None                                      | PASS                                                              |
| URLs, UPI IDs, notes and QR payloads             | Forbidden                                    | Not logged | Only user-entered search/tool slug paths; QR data excluded | None                                      | PASS                                                              |
| Uploaded logos/document content                  | Forbidden                                    | Not logged | Not placed in URL                                          | None                                      | PASS                                                              |
| Contact name, email, topic and message           | Not tracked                                  | Not logged | Not placed in URL                                          | None                                      | Sent only to configured contact recipient; exclude sensitive data |
| Aggregate tool/search events                     | Allowlisted names and low-risk metadata only | N/A        | N/A                                                        | N/A                                       | PASS; no transport configured                                     |

Storage audit: Phase 2 adds one explicit, tab-only `sessionStorage` handoff for business-economics scenarios. It is written only after the user selects “Save for a related tool”, is bounded and versioned, imports only matching field names after a second user action, and is cleared when consumed or when the tab closes. No `localStorage`, IndexedDB or cookie writes exist. All other data is held in React/page memory and clears on reload. Safe error logging accepts only feature/code/digest fields in development and never form state.

The contact form now posts to a server-side route that validates the fields and sends a plain-text message through the configured Resend account. The API key and recipient are server-only environment variables; the route does not log message contents. The Resend recipient and privacy/retention settings must be confirmed before public launch. Error reports remain local-only and do not claim delivery.

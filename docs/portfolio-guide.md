# KarobarKit product portfolio

Current objective: demonstrate product judgment, analytical reasoning and delivery for a first product/growth/operations role. Recruitment, interviews, acquisition campaigns, retention studies and monetization validation are deliberately skipped. Historical pilot templates remain reference material, not a current execution requirement. No participant data is needed.

## Public artifact

/case-study presents the problem hypothesis, decisions, real verification failures and fixes, analytical demonstration, limitations and conditional roadmap. /research is paused; new research API submissions are rejected. General feedback remains available.

The funnel demo uses 12 invented sessions in two deliberately modeled scenarios. It counts unique session/stage combinations, requires start → result → export sequencing and reports a completion denominator and median duration. Downloaded JSON can be reproduced with public/portfolio/funnel.sql in SQLite using a bound events_json parameter. This is not an A/B test, measured uplift, acquisition experiment or evidence of real users. Vercel custom-event collection remains disabled on Hobby.

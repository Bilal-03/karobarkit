# Project calculator availability

For this personal project, elapsed source-review dates are informational and do not disable working tools. Tax, HRA, payroll, GST invoices, HSN reference search, GST calendar, depreciation, professional tax, MSME interest and marketplace fees continue to calculate with their bundled snapshots. Marketplace seller fee overrides remain optional where bundled fees exist.

Review dates and freshness metadata remain unchanged. Notices explain that later changes may not be included; this change does not assert a new official review or update formulas. A transaction or marketplace policy date after the last review can use an otherwise applicable active snapshot.

Input validation, supported assessment years, actual effective date ranges, source integrity, explicitly unavailable category fees, feature flags and kill switches still apply. The calculators do not file returns or submit payroll records.

Regression coverage exercises calculation after review expiry, current-date invoice creation, optional marketplace overrides, and browser form submission for every tax/payroll calculator.
